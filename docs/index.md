# AutoMapConverter

AutoMapConverter converts Lanelet2, OpenDRIVE and OSM road maps and produces
topology-aware semantic rasters for autonomous-driving workflows. It exposes
seven directed workflows, traceable diagnostics and a stable Python/CLI
boundary for future GUI integration.

Start with the [workflows](conversion_workflows.md), then use the
[Python API](api.md), [CLI](cli.md), or the dedicated
[Lanelet2 raster guide](lanelet2_raster.md). The Chinese presentation copy and
video storyboard for OnSite integration are maintained in the
[OnSite showcase brief](onsite_map_conversion_showcase.md).
